# exo

Mobile-first οδηγός θεάτρου και συναυλιών στην Αθήνα.

## Λειτουργίες

- Πραγματικός επιμελημένος κατάλογος στο `data/catalog.json`, με αναλυτικές πηγές και χρόνο ελέγχου.
- Αναζήτηση χωρίς τόνους σε τίτλο, χώρο, περιοχή και συντελεστές.
- Φίλτρα είδους, ημέρας, περιοχής και ύπαρξης κριτικών, ταξινόμηση.
- Χωριστές κριτικές συντακτών και κοινού, πρωτότυπο URL, συντάκτης και ημερομηνία όπου τεκμηριώνεται.
- Αγαπημένα στη συσκευή και κοινοποίηση συνδέσμου συγκεκριμένης παραγωγής.
- Επιβεβαίωση προγράμματος μόνο από πρόσφατο έλεγχο επίσημου χώρου ή προπώλησης. Η ένδειξη λήγει σε 72 ώρες.
- Οι πληροφορίες από πολιτιστικό οδηγό παραμένουν ορατές με ένδειξη ότι απαιτείται επιβεβαίωση.

## Εκκίνηση και έλεγχοι

Node.js 22 ή νεότερο. Χωρίς εγκατάσταση εξαρτήσεων.

```sh
node preview.mjs
node --test tests/core.test.mjs
```

Προεπισκόπηση: http://127.0.0.1:4175/

## Δημοσίευση

GitHub Pages από το branch `main`, φάκελος `/ (root)`. Όλες οι διαδρομές είναι σχετικές ώστε να λειτουργούν στο `/exo/`.

## Επιμέλεια

Ενημερώνουμε το `data/catalog.json` μόνο ύστερα από έλεγχο των συνδεδεμένων πηγών. Το `lastCheckedAt` δεν ανανεώνεται αυτόματα ούτε με κάθε επίσκεψη. Χωρίς τεκμηριωμένη κλίμακα βαθμολογίας, το `score` μένει `null`. Άγνωστη ημερομηνία δημοσίευσης μένει `null`.

Οι εμφανίσεις από εβδομαδιαίο πρόγραμμα είναι οι ανακοινωμένες ημέρες, εντός του τεκμηριωμένου διαστήματος· δεν αποτελούν διαβεβαίωση διαθεσιμότητας ή μη ακύρωσης.

Η πρώτη έκδοση περιλαμβάνει 6 παραγωγές/εκδηλώσεις και 4 κριτικές για τις «Ευτυχισμένες μέρες». Δεν αποτελεί πλήρη κατάλογο της Αθήνας. Δεν υπάρχουν συνθετικές αξιολογήσεις κοινού, λογαριασμοί ή αυτόματη συλλογή. Οι αφαιρετικές κάρτες σχεδιάζονται με CSS χωρίς χρήση φωτογραφιών τρίτων.

Η μεθοδολογία και οι περιορισμοί περιγράφονται στο [DATA_SOURCES.md](DATA_SOURCES.md).
