# exo
Οδηγός θεάτρου και ζωντανής μουσικής στην Αθήνα: https://danal8.github.io/exo/

## Πληροφορίες μέσα στην κάρτα
Αφίσα ή φωτογραφία παραγωγής, σύντομη παρουσίαση με πρωτότυπη πηγή, συντελεστές, χώρος και χάρτης, διάρκεια όπου υπάρχει, τιμές, πρόγραμμα, κριτικές συντακτών και βαθμολογία/σύνδεσμος κοινού. Άγνωστα στοιχεία δηλώνονται ως μη διαθέσιμα. Φίλτρα περιοχής, χώρου, ημέρας, κατηγορίας και βαθμολογίας κοινού.

## Πώς ενημερώνεται
Το GitHub Action `.github/workflows/refresh-catalog.yml` εκτελείται κάθε έξι ώρες (00:17, 06:17, 12:17, 18:17 UTC), καθώς και χειροκίνητα από Actions → Refresh theatre and music guide → Run workflow. Η εκτέλεση του GitHub μπορεί να καθυστερήσει.

- Ανακάλυψη από οδηγούς θεάτρου/μουσικής Αθηνοράματος, κατηγορίες More/Public και τα δηλωμένα ημερολόγια επίσημων χώρων.
- Επανέλεγχος των συνδεδεμένων σελίδων κάθε υπάρχουσας καταχώρισης.
- Συλλογή μεταδεδομένων, εικόνας, σύντομης παρουσίασης, συντελεστών, τιμών, διάρκειας και αναλυτικών συνδέσμων κριτικών όπου αναγνωρίζονται.
- Ενημέρωση απλού ελληνικού εβδομαδιαίου προγράμματος. Σύνθετες ημερομηνίες δεν μετατρέπονται αυθαίρετα σε επαναλαμβανόμενες παραστάσεις.
- Νέα παραγωγή δημοσιεύεται αυτόματα μόνο με τίτλο, χώρο στην Αθήνα και μελλοντική ημερομηνία. Αμφίβολες ταυτίσεις μπαίνουν στις υποψήφιες εγγραφές του report.
- Ακυρωμένες και αναβληθείσες παραγωγές αποσύρονται από την ανακάλυψη όταν η πηγή τις δηλώνει ρητά.
- Οι υπάρχουσες πληροφορίες διατηρούνται όταν μια πηγή αποτύχει. Η επιβεβαίωση παύει να ισχύει σε 72 ώρες.

## Τι σημαίνει «επιβεβαιωμένο»
Πρόσφατη ανάγνωση μελλοντικής ημερομηνίας/ανακοινωμένου διαστήματος από προπώληση ή επίσημο χώρο. Ένα HTTP 200, μια εικόνα, ένας σύνδεσμος αγοράς ή η ανανέωση της σελίδας δεν αρκούν. Δεν αποτελεί εγγύηση διαθέσιμης θέσης.

## Πραγματικά όρια κάλυψης
Δεν υπάρχει καθολικό δημόσιο API που να καλύπτει όλα τα θέατρα και όλες τις μουσικές σκηνές. Σελίδες που απαιτούν JavaScript, μπλοκάρουν πρόσβαση, δεν δίνουν ημερομηνίες ή έχουν αμφίσημα στοιχεία δεν χαρακτηρίζονται ελεγμένες. Η αυτόματη ανακάλυψη είναι περιορισμένη στις δημόσιες σελίδες εισόδου και δεν εγγυάται όλες τις σελίδες μιας πλατφόρμας. Ο κατάλογος δεν παρουσιάζεται ως πλήρης ή ως live διαθεσιμότητα.

Οι βαθμολογίες κοινού παραμένουν χωριστές από τις κριτικές συντακτών. Ανανέωση αριθμητικού μέσου γίνεται μόνο αν η πηγή τον επισημαίνει ρητά ως μέσο κοινού. Δεν μετατρέπουμε το γενικό schema.org aggregateRating σε βαθμολογία θεατών. Οι ήδη καταχωρισμένες βαθμολογίες διατηρούν τον πραγματικό χρόνο ελέγχου τους· ο επανέλεγχος μιας σελίδας δεν ανανεώνει αυτόματα τη βαθμολογία.

## Έλεγχοι
Node.js 22+, χωρίς εξαρτήσεις:
```sh
node --test tests/*.test.mjs
node scripts/refresh-catalog.mjs
node preview.mjs
```
Αναλυτικό αποτέλεσμα κάθε κύκλου: `data/refresh-report.json` (κάλυψη, σφάλματα, νέες υποψήφιες παραγωγές). Δεν εκτελείται συλλογή από το κινητό του επισκέπτη. Το Pages σερβίρει τον τελευταίο δημοσιευμένο κατάλογο.

Οι λογαριασμοί και οι ιδιωτικές κρατήσεις διατηρούν την υπάρχουσα λειτουργία τους. Η αποθήκευση κράτησης στο exo δεν αγοράζει ούτε ακυρώνει εισιτήριο.
