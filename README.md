# exo

Mobile-first οδηγός θεάτρου και συναυλιών στην Αθήνα.

## Λειτουργίες

- Πραγματικός επιμελημένος κατάλογος στο `data/catalog.json`, με αναλυτικές πηγές και χρόνο ελέγχου.
- Αναζήτηση χωρίς τόνους σε τίτλο, χώρο, περιοχή και συντελεστές.
- Φίλτρα είδους, ημέρας, περιοχής και ύπαρξης κριτικών, ταξινόμηση.
- Χωριστές κριτικές συντακτών και κοινού, πρωτότυπο URL, συντάκτης και ημερομηνία όπου τεκμηριώνεται.
- Αγαπημένα στη συσκευή και κοινοποίηση συνδέσμου συγκεκριμένης παραγωγής.
- Επιβεβαίωση προγράμματος μόνο από πρόσφατο έλεγχο επίσημου χώρου ή προπώλησης. Η ένδειξη λήγει σε 72 ώρες.
- Οι πληροφορίες από πολιτιστικό οδηγό παραμένουν ορατές με ένδειξη ότι απαιτείται επιβεβαίωση.

## Εκκίνηση και έλεγχοι

Node.js 22 ή νεότερο. Χωρίς εγκατάσταση εξαρτήσεων.

```sh
node preview.mjs
node --test tests/core.test.mjs
```

Προεπισκόπηση: http://127.0.0.1:4175/

## Δημοσίευση

GitHub Pages από το branch `main`, φάκελος `/ (root)`. Όλες οι διαδρομές είναι σχετικές ώστε να λειτουργούν στο `/exo/`.

## Επιμέλεια

Ενημερώνουμε το `data/catalog.json` μόνο ύστερα από έλεγχο των συνδεδεμένων πηγών. Το `lastCheckedAt` δεν ανανεώνεται αυτόματα ούτε με κάθε επίσκεψη. Χωρίς τεκμηριωμένη κλίμακα βαθμολογίας, το `score` μένει `null`. Άγνωστη ημερομηνία δημοσίευσης μένει `null`.

Οι εμφανίσεις από εβδομαδιαίο πρόγραμμα είναι οι ανακοινωμένες ημέρες, εντός του τεκμηριωμένου διαστήματος· δεν αποτελούν διαβεβαίωση διαθεσιμότητας ή μη ακύρωσης.

Η πρώτη έκδοση περιλαμβάνει 41 παραγωγές/εκδηλώσεις (24 θέατρο, 17 μουσική), 6 επώνυμες κριτικές και 5 τρέχουσες βαθμολογίες συντακτών από το Αθηνόραμα. Δεν αποτελεί πλήρη κατάλογο της Αθήνας. Δεν υπάρχουν συνθετικές αξιολογήσεις κοινού ή αυτόματη συλλογή. Υποστηρίζονται λογαριασμοί και ιδιωτικές κρατήσεις. Οι αφαιρετικές κάρτες σχεδιάζονται με CSS χωρίς χρήση φωτογραφιών τρίτων.

Η μεθοδολογία και οι περιορισμοί περιγράφονται στο [DATA_SOURCES.md](DATA_SOURCES.md).

## Λογαριασμοί και κρατήσεις

Αυτοεγγραφή με email/κωδικό, σύνδεση, αποσύνδεση, αίτημα ανάκτησης κωδικού. Supabase JS 2.118.0, αποθηκευμένο στο vendor με την άδεια MIT. Το config περιέχει μόνο δημόσιο publishable key.

Ο πίνακας `public.exo_tickets` στο υπάρχον project χρησιμοποιεί RLS και `auth.uid() = user_id` για κάθε ανάγνωση, εισαγωγή, αλλαγή και διαγραφή. Ο ρόλος anon δεν έχει πρόσβαση. Δεν εισάγονται αυτόματα αγορές από More.

Πεδία κράτησης: τίτλος, χώρος, ημερομηνία, ώρα, ιδιωτικό URL εισιτηρίου, κωδικός κράτησης, σημειώσεις και κατάσταση. Διαγραφή στο exo δεν ακυρώνει την αγορά στον πάροχο.

Οι επιτρεπόμενες διευθύνσεις επιστροφής περιλαμβάνουν `https://danal8.github.io/exo/` και `https://danal8.github.io/exo/?recovery=1`. Το υπάρχον Site URL των άλλων εφαρμογών δεν άλλαξε. Η παράδοση email ανάκτησης εξαρτάται από τη διαμόρφωση email του project και δεν δοκιμάστηκε με πραγματικό email χρήστη.

## Έλεγχος UI

Στο κινητό οι λεπτομέρειες και ο λογαριασμός καταλαμβάνουν όλη την οθόνη, με επιστροφή μέσω ιστορικού browser. Στο web οι λεπτομέρειες έχουν μέγιστο πλάτος 1040px. Οι διευθύνσεις ανοίγουν Google Maps. Τα τεκμήρια πηγών διατηρούνται στα δεδομένα και δεν εμφανίζονται ως τεχνικές σημειώσεις στο UI.
